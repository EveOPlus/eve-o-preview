# Aura Asuna portrait

`aura-asuna.jpg` is the 128-pixel portrait for EVE character **Aura Asuna**,
ID **95465272**, retrieved on 2026-09-07 from FC's public image service:

https://images.evetech.net/characters/95465272/portrait?size=128

This image is a test fixture for the smoke backend's delayed portrait response.
It is embedded only in the test executable. The production app retrieves the
current portrait asynchronously from FC and caches it by character ID; it does not bundle this fixture.
EVE imagery belongs to FC hf.; the image service permits its use in applications:
https://developers.eveonline.com/docs/services/image-server/
