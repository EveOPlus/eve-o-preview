## Existing capabilities and scope

Already implemented: hot-swappable profiles, unlimited cycle groups, single-character hotkeys via one-member groups, hotkey tooltips, FPS throttling/prediction, automatic affinity, gate/banner muting, custom mute IDs, Minimize All, Hide All, neighbor snapping, context move/resize, Shift aspect-ratio resizing and latest-activated-preview raising. Presence does not establish correctness in every environment.

Arbitrary non-EVE processes, cross-platform support and changes to input forwarding require explicit scope decisions. Current implementation targets EVE on Windows. Multiple independent cycle groups sharing one shortcut need conflict semantics; offline characters can already share one ordered group.

For future tasks, name a FEAT ID, read its source route and related BUG IDs, recheck current implementation and establish acceptance criteria. Update this page with the implementation commit and validation when complete.
